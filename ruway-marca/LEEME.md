# LEEME — Documentos de marca RUWAY

Este paquete **reencauza** los 6 documentos que el brief de proyecto esperaba encontrar
(`IDENTITY`, `SOUL`, `USER`, `AGENTS`, `TOOLS`, `HEARTBEAT`).

**Por qué existe esta carpeta:** en la raíz del workspace, esos nombres corresponden en
realidad a las plantillas operativas del asistente (identidad del agente, protocolo de
seguridad, notas de entorno). Se dejaron intactos para no romper el workspace. Aquí viven
las versiones **de RUWAY**.

| Documento | Qué define |
| :--- | :--- |
| `IDENTITY.md` | Núcleo de marca: nombre, eslogan, misión, visión, tono de voz, paleta, tipografía, símbolo |
| `SOUL.md` | Filosofía, valores y principios de experiencia |
| `USER.md` | Perfiles de usuario, unidad de decisión y recorrido de compra |
| `AGENTS.md` | Equipo, roles y modelo de remuneración |
| `TOOLS.md` | Herramientas del programa académico y equipamiento de la sede |
| `HEARTBEAT.md` | Ritmo operativo: sesión, semana, ciclo, calendario |

**Fuente de verdad:** `../plan completo.md` (v2.0). Todo dato aquí proviene de él o de
`../ruway-identidad/LEEME.txt`. Lo que no existe en los insumos se marca `[POR DEFINIR]`.

> ⚠️ Nada de este paquete inventa cursos, precios, sedes o fechas.
